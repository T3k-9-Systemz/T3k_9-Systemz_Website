canENDR

A tiny PCB terminator for FRC CAN-bus lines.

Problem / context

FRC CAN-bus lines need termination; canENDR packages that function into a small board intended to tuck into a robot.

Design / approach

The PCB places a 2×1 WAGO terminal block and a 120Ω SMD resistor in a footprint just under 1 × 0.75 inches.

Engineering decisions

The documented component choices are the WAGO terminal block and 120Ω SMD resistor. The current source does not record selection tradeoffs or validation measurements.

Constraints

The primary documented constraint is size: it needed to be small enough to fit into a robot.

Implementation

PCB design for an FRC electrical application.

Status / results

Complete. Finished in July 2026.

Lessons learned

Lessons are not yet documented in the source material.
