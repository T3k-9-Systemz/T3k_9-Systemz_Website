MakoPad Mk1

A custom six-key macropad for helping FRC programmers work faster during build season.

Problem / context

FRC programmers need a compact, programmable input device for repetitive controls and development workflows during build season.

Design / approach

MakoPad Mk1 is designed from the ground up in KiCad and programmed with QMK. The build combines a six-key layout with an LCD, hot-swappable switches, a rotary encoder, and layer control.

Engineering decisions

The documented design uses hot-swappable switches, a 1.8-inch LCD, and a rotary encoder for layer control. The enclosure work is in Fusion 360; the source does not yet document the reasoning behind each component selection.

Constraints

The device is intended to be compact and useful during FRC build season. More detailed physical, electrical, and firmware constraints can be added from design notes or the repository.

Implementation

KiCad, QMK, PCB design, and Fusion 360 are part of the documented toolchain.
