Weightlifting Calculator

A straightforward calculator for weightlifters — and the project where the basics of Java began to click.

Problem / context

The project was built as a practical calculator for weightlifters. Rather than beginning with a large application, the goal was to create something focused enough to learn the fundamentals of Java while producing a usable result.

Design / approach

The calculator was intentionally straightforward. The project focused on taking inputs, performing the required calculations, and presenting the resulting values clearly.

Engineering decisions

The most important decision documented by the project history was keeping the scope focused. As a first Java program, reducing unnecessary complexity made it possible to concentrate on learning the language and its basic programming structure.

Constraints

The primary constraint was experience: this was my first Java program. The project therefore had to be approachable enough to finish while still giving me a practical reason to learn Java fundamentals.

Implementation

The project was implemented in Java. Specific classes, calculation methods, and interface details are not documented in the current portfolio source and can be added here from the project repository.

Status / results

Complete. This was my first Java program and the project where the fundamentals of Java started to click.

Lessons learned

The main result was not just the calculator itself. Building something small enough to understand end-to-end gave me a practical way to learn Java and established a foundation for taking on larger software projects later.
